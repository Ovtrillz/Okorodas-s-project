# 🌎 Planet Explorer

## Project Overview

Planet Explorer is a web-based application developed to help users explore information about the planets in our solar system. Users can search for planets by name and view details about their physical characteristics and orbital properties.

The application displays information such as gravity, mass, orbital period, temperature, number of moons, diameter, and distance from the Sun. It also features a light and dark mode toggle for an improved user experience.

The project was developed using HTML, CSS, JavaScript, and JSON.

## Live Deployment

**Live Website:** https://capstone-project-ov.vercel.app/

## Technologies Used

- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used to style the website and create its visual layout.
- **JavaScript:** Used to implement planet searching, dynamic content updates, data loading, and theme switching.
- **JSON:** Used to store planetary information.
- **Git:** Used for version control.
- **GitHub:** Used to host the project's source code.
- **Vercel:** Used to deploy the website.

## How to Run the Project Locally

### Requirements

To run the project locally, you will need:

- A computer with a modern web browser.
- Visual Studio Code.
- The Live Server extension for Visual Studio Code.

### Installation and Setup

1. Clone the repository using Git:

   ```bash
   git clone https://github.com/Ovtrillz/Okorodas-s-project.git
   ```

2. Open the downloaded project folder in Visual Studio Code.

3. Ensure that the HTML, CSS, JavaScript, JSON, and media files are present.

4. Install the Live Server extension in VS Code if it is not already installed.

5. Open `index.html`, right-click inside the editor, and select **Open with Live Server**.

6. The application will open in your default browser. You can search for planets and explore the available features.

**Note:** Use Live Server instead of opening the HTML file directly from your computer. The application loads planetary information using JavaScript's `fetch()` function, which requires the files to be served over HTTP for local testing.
